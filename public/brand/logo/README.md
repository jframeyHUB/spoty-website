# SPOTY logo files (gold, one colour)

The logo is one colour only: SPOTY Gold #C9971C. Every detail (the ring, laurel, star and the "1") is cut out of the gold, so the same file works on white, navy, photos, and for engraving or foil printing. There are no separate "on dark" versions.

All text is converted to outlines, so the files look identical on any computer. No fonts need installing.

## Fonts (for everything that isn't the logo)
App: the phone's system font (San Francisco / Roboto / Segoe UI). Award titles and certificates: Bodoni Moda (free, Google Fonts, Open Font License).

## Rules
- Keep clear space around the logo at least the height of the "S" in SPOTY.
- Gold only: don't recolour, add colours, stretch or rotate it, or remove the ribbons.
- The gold is softer on pure white. For small sizes on white, prefer the navy app icon or a navy background.
